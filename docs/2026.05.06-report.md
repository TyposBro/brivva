## Main failure discovered: FFmpeg crash/restart ends YouTube stream

In run 3, FFmpeg pushed normally for ~97 seconds, then crashed.

Key CloudWatch events:

```text
2026-05-06T01:31:20.806Z [AUDIO:<stream>] write error, exiting
2026-05-06T01:31:20.824Z [VIDEO:<stream>] H.264 pipe write error, exiting
2026-05-06T01:31:21.878Z ffmpeg rtmp process crashed, scheduling restart exit_code=-1
2026-05-06T01:31:21.878Z output.degraded degradation=FfmpegCrash message="ffmpeg exit_code=-1"
2026-05-06T01:31:23.880Z output.restarting
2026-05-06T01:31:23.882Z output.live restart_count=1
2026-05-06T01:31:23.882Z ffmpeg rtmp restarted
```

Brivva UI/provider health marked output as reconnecting/unbillable.

Critical observation:

- Brivva returned output state to `Live` after restart.
- But YouTube VOD stopped at `1:37`.
- The stream did not continue as one healthy viewer stream.

Conclusion:

- For YouTube auto-created broadcasts with `enableAutoStop: true` and non-reusable streams, an FFmpeg crash/reconnect may end the YouTube broadcast. Brivva’s internal restart state can be misleading because YouTube may have already finalized the broadcast/VOD.
- The product should treat YouTube FFmpeg crash/restart as terminal or create a new broadcast/watch URL after a crash, unless YouTube behavior is explicitly verified otherwise.

Possible contributing logs immediately before crash:

```text
[AUDIO:<stream>] fifo write backpressure would_blocks=20
[AUDIO:<stream>] stats ... fifo_would_blocks=5522 fifo_skipped_ticks=110 ...
[AUDIO:<stream>] write error, exiting
[VIDEO:<stream>] H.264 pipe write error, exiting
```

This suggests FFmpeg child exited or closed stdin pipes; audio/video drainers then observed pipe write errors. Need root-cause by preserving full FFmpeg stderr around exit and/or detecting output-side errors, not only exit code.

- Current fake video fixture is 1920x1080 landscape, but app constraints crop it to portrait. For deterministic tests, generate a true `720x1280 @ 30fps` or `1080x1920 @ 30fps` portrait fixture instead.
